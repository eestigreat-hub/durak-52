# Дурак — 52 карты

Подкидной и переводной дурак. Игра с компьютером или другом по ссылке.

[Открыть игру](https://eestigreat-hub.github.io/durak-52/)

Для игры с другом создатель стола должен оставить вкладку открытой. Ходы зашифрованы и передаются через бесплатные публичные ретрансляторы. Аккаунты и платные ключи не нужны. Доступность внешних сервисов может меняться.

Готовая сборка размещена в корне. Исходники, тесты, оригинальные SVG и скрипт подготовки загрузки — в source.zip. После распаковки: Node.js 22.13+, npm install, npm run dev. Сборка: npm run build.
